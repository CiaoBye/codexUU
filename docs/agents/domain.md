# Domain documentation

CodexUU uses a single-context layout. The root `AGENTS.md` is the binding product
and collaboration specification; `README.md` documents the user-visible
Windows product and data boundaries; `agents/changelog.md` records delivered
changes and verification results. No separate `CONTEXT.md` or ADR tree exists
yet. New domain decisions should be recorded in `docs/adr/` when they become
hard to reverse.
